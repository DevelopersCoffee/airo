# feature_anya_core

Pure Dart domain for **Anya** — Your Personal Nutrition Planner.

Entities, the seeded meal catalog, weekly plan generation, grocery
aggregation, and heuristic PDF normalization live here. No Flutter, no
`core_ai`, no Mind plugin.

See `docs/superpowers/specs/2026-09-10-anya-mvp-design.md`.
