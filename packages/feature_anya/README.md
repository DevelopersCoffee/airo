# feature_anya

Flutter UI and `AnyaModule` for **Anya** — Your Personal Nutrition Planner.

Depends on `feature_anya_core`. Does not depend on `core_ai` or `feature_mind`.
PDF text extract uses `syncfusion_flutter_pdf` (community license) behind
`AnyaPdfTextExtractor` and runs off the main isolate via `runOffMain()`.

See `docs/superpowers/specs/2026-09-10-anya-mvp-design.md`.
