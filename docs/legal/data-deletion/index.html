Request deletion

This page is the Google Play data-deletion resource for Aika Stream (com.developerscoffee.tv.midas), published by DevelopersCoffee.

Use this page to request deletion of Aika Stream data. You do not need to reinstall the app. Email is enough.

Email a deletion request Read the privacy policy

Send the request from a mailbox we can reply to. Include the words Aika Stream and, if you have it, the Google Play order or device model. We respond within 30 days. There is no developer-hosted Aika Stream account to cancel first.

What DevelopersCoffee holds

Aika Stream is a local media player for playlists you add. DevelopersCoffee does not collect, receive, or store playlist URLs, channel lists, favorites, watch history, names, emails, or payment data for TV playback.

That means there is usually no profile on our servers to erase. A deletion request still gets a human reply confirming that, or erasing any record we unexpectedly hold (for example an email you sent us).

Delete data on your device

Everything Aika Stream stores for playback lives on the device. Any of these paths erase it:

  1. Android / Google TV: Settings → Apps → Aika Stream → Storage → Clear storage (or Clear data). This removes saved sources and credentials, guide URLs, favorites, watch history, and preferences.
  2. Uninstall Aika Stream. Uninstalling removes app storage, including the Firebase installation ID described below.

Clearing storage or uninstalling is immediate and does not require contacting us.

Firebase installation ID

Aika Stream includes the Firebase core library so the app can start. It does not include Firebase Analytics, Crashlytics, or Cloud Messaging. Where Firebase creates a random Firebase installation ID, that identifier is sent to Google under the Google Privacy Policy. DevelopersCoffee does not receive it, does not link it to you, and does not use it for advertising.

Clearing app storage or uninstalling Aika Stream resets that identifier. A deletion email cannot delete a Google-held installation ID on your behalf; use clear-data or uninstall for that.

Accounts

Aika Stream does not offer account creation or sign-in for playback. There is no DevelopersCoffee username, password, or cloud playlist account associated with the app.

If you later used a playlist provider (Xtream, Jellyfin, or similar) inside Aika Stream, those credentials are stored only on the device. Clear storage or uninstall to remove them. We cannot delete an account that exists only on a third-party provider you chose.
