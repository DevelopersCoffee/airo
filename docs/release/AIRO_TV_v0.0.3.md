# Aika Stream v0.0.3

Aika Stream v0.0.3 is the Play drop for two-pane MultiView that snaps 5/50/95,
keeps a short premium handle, and mixes the two streams with the bar.

## Highlights

- Two-pane live split snaps to **5 / 50 / 95**, with an 80dp min pane so a
  phone never gets an 18px sliver.
- Dragging the handle crossfades the two videos with equal-power gains.
  System volume does not change.
- Compact (either axis under 600dp) uses a **48dp** full-seam hit; TV and
  tablet landscape use **24dp**. Paint is a 2dp hairline plus an 8×28
  stadium in the middle third.
- Resume the last live channel on launch (already on Internal 22).
- Play `versionName` **0.0.3**, `versionCode` **23**. Do not reuse 22.

## New Features

### IPTV

- Two-pane MultiView mix follows pane order, not the featured tile.
- Tile volume sliders stay in triple/quad; two-pane hides them.

### Android TV

- D-pad focuses the handle. Left/Right (or Up/Down if stacked) steps
  5 / 50 / 95 with no wrap at the extreme.
- Select/OK on the handle is still a no-op.

### Playback

- Leaving two-pane restores exclusive featured audio.
- Cast mute-all stays silent in two-pane instead of remixing.

### User Interface

- Phone, tablet, and Android TV / D-pad remain one listing
  (`leanback` not required).

## Improvements

- Magnetic stops replace the 30/70 clamp from Internal 22.
- Handle paint is a short grip instead of a full-height slab.

## Bug Fixes

- Two-pane `muteAll()` no longer unmutes tiles on the next pool sync.

## Performance

- Both `buildView()` surfaces stay mounted. Mix does not reopen decoders.
- Android two-pane decoder budget stays 2.

## Developer Changes

- `app/pubspec_tv.yaml` is `0.0.3+23`. Sync the TV package-info stub with
  `scripts/aika_stream_version.sh --sync-stub`.
- Design: `docs/superpowers/specs/2026-09-24-multiview-dj-split-design.md`.

## Breaking Changes

No breaking changes.

## Known Limitations

- No recording.
- No cloud favorites sync.
- No cloud playlists.
- Triple and quad mosaics have no split handle.
- Cast protocol is unchanged.

## Installation

### APK

Sideload uses the upload key. Uninstall a sideload before installing from
Play — Play App Signing will not upgrade a sideload in place.

### Play Store

Drop `Aika-Stream-0.0.3-23.aab` on Internal testing, then promote.
Testers on Play 22 upgrade in place. Never reuse versionCode 22.
