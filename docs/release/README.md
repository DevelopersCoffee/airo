## Previous: Aika Stream v0.0.5

### New Features
- **Focused product surface** - Aika Stream is the active IPTV product target; obsolete Streaming/IPTV release targets are removed.
- **Filters and setup** - First-run country selection, country/language/category filters, and deduplicated category values.
- **Player controls** - Consistent Aika Stream overlay controls across compact portrait, landscape, and fullscreen playback.
- **Channel warmup** - Bounded health checks and nearby-channel warmup improve channel switching responsiveness.

```bash
git push origin v1.2.0
```
