## Problem Statement

People browsing Aika Stream's channel grid cannot tell what is on. They tap a channel, wait for first frame, back out, try another. A person watched doing this asked "what's on?" and looked for now-playing text that is not on the tile. The grid today is logos plus category/country/language. Instagram Reels (every visible tile is a live stream) is the wrong product for live IPTV.

## Demand Evidence

- Status-quo loop: tap, wait, back, try another.
- Observation: someone else browsed unhelped and hunted missing now-playing text.
- No revenue or named individual. Thin behavioral demand. Wedge to test, not a paid feature.

## Status Quo

- `ChannelLibraryGrid` tiles: logo + category/flag/language. `ChannelBrowseMetadata` has country/language only.
- Guide tab already has EPG (`guide_providers.dart`, remapped `CompactEpgWindow`, `nowTickerProvider` at 30s, `epgProgramIsAiring`).
- Mini Guide on Watch: one muted live preview on the focused card after 500ms.
- MultiView: up to 4 live tiles, separate mode, `kAiroMultiviewHardCap = 4`.
- Ten-foot browse (`playlistSourceInInfoBar`): `focusPlayDelay` is 1200ms and calls `onChannelSelected`, which starts fullscreen Watch. Phone: delay is null (tap plays).

TiviMate Premium retunes **one** preview window while scrolling EPG. Multi-screen is a separate mosaic. IPTV Now/Next text is what makes a player feel like TV.

## Target User & Narrowest Wedge

A person with their own M3U, in the library grid, identifying the current program without committing to Watch.

v1: now-playing title on tiles when EPG matches, plus **one** muted peek on TV/D-pad focus. Not a mosaic.

## Constraints

- Decoder budget: hard cap 4; Android/iOS provider returns 2; many Fire TV boxes sustain 1. A second ExoPlayer often fails or kills the first (ExoPlayer #9707, #2713).
- TV 19 said: Watch owns the main session; Mini Guide may own one muted preview; destinations must not hold a session. **This spec amends that:** Library may hold the same class of session Mini Guide holds (one muted, control-free peek) with identical teardown. Owner: `feature_iptv` browse controller. Allowed surface: `ChannelLibraryGrid` on TV/D-pad only. Leave Library, change filters/search signature, open Watch, or start Cast: STOP and dispose peek. Peek and Mini Guide must never both exist.
- Ghost audio remains a ship-blocker. Mute + `mixWithOthers: true` is not enough; stop/dispose must drop Exo/media-session/audio focus (same tests as Mini Guide). Also STOP+dispose on `AppLifecycleState.inactive`/`paused`, Search overlay, rail focus leaving the grid, and any modal.
- Web: no-op preview factory (compile-out / stub). Do not probe at runtime.
- Compact-grid density APIs on the current chrome branch may be absent on `origin/main`. Implement against main's grid. Do not assume `_CompactGridMediaCard` exists.
- Peek must not log playlist/stream URLs (same privacy rule as TV 19).
- Copy this TV 19 amendment into `docs/superpowers/specs/2026-09-16-aika-stream-tv-19-design.md` in the same PR as the peek.

## Premises

1. The job is answering "what's on?" from the grid, not looking like Instagram.
2. One muted preview decoder is the maximum on browse. A Reels mosaic is MultiView.
3. A second decoder must never tear down Watch or Cast.
4. EPG now-playing text belongs on tiles when data exists. Live video confirms the stream is up and fills missing EPG.
5. Reuse Mini Guide's factory and state machine; do not add a player stack.

## Landscape

- Layer 1: Live TV browse is Now/Next EPG plus one preview pane. Mosaics are a separate watch-four mode.
- Layer 2: TiviMate users want preview-while-scrolling, not 12 live thumbs. Hardware decoder caps are 1–4.
- Layer 3: Reels assumes cached clips. Live HLS is a new session per tile. The observed job is "what's on?"

## Recommended Approach

Approach A.

### Locked v1 matrix

| Surface | Now-playing text | Live peek |
|---|---|---|
| Phone touch | Yes, all layouts that show a subtitle | No |
| TV / D-pad | Yes | Yes, focused tile only |
| Web | Yes if EPG loaded | No (stub factory) |
| Audio-only / ad slot / empty URL | Text if any | No |

Phone live-peek (press-and-hold vs actions sheet) is v1.1, not designed here.

### EPG data contract

- New derived provider, e.g. `browseNowPlayingByChannelIdProvider` → `Map<String, String>`.
- Source: remapped `CompactEpgWindow` (same override + `tvg-id` / `epgLookupIds` path as Guide). Key is playlist `channel.id` after remap, never raw xmltv id.
- Library **may** subscribe and cold-start `guidePagedWindowProvider`. The window is not assumed warm. Until `window == null` / loading / load-failed: omit keys, keep category subtitle.
- v1 loads the same initial Guide window (`guideInitialForward`, 6h) over the current playlist. Visible-id-only query is a later optimization, not v1.
- Value: current airing program title. Omit the key if no match, not airing, or title is empty. Use `epgProgramIsAiring` only as the time predicate.
- Rebuild the **map** on `nowTickerProvider` (30s), not every tile widget. Tiles `select` their own id.
- Dense layouts that currently drop the subtitle: keep dropping it. Do not raise row extent in v1. Success criterion for those layouts is "no overflow," not "title visible."
- Unmatched `tvg-id`: omit key, keep today's category subtitle.
- Replace the category subtitle with one line of now-title (ellipsis). Do not add a second line. Do not add a second LIVE badge on horizontal cards that already have LIVE.

### Peek controller (grid-level, not per-tile)

- One controller owned by `ChannelLibraryGrid`. Duplicate Mini Guide **only** for epoch, settle, mute-before-play, and fail-closed. Do **not** copy Mini Guide `_selectChannel` (that fires `onSelected` without awaiting dispose).
- Factory: `tvMiniGuidePreviewFactoryProvider` (`VideoPlayerStreamingService(mixWithOthers: true)`).
- **Attach strategy (locked):** overlay a single `buildVideoView()` on the focused tile's thumbnail rect (`LayerLink` / `CompositedTransformFollower` or equivalent). It is **not** a child of the sliver cell. Wrap it `IgnorePointer` + platform `focusable: false` so D-pad stays on the grid after first frame. Do not put `AndroidView` inside recycled grid children. If that rect leaves the viewport, stop. `buildVideoView` call count stays 1 while scrolling past many tiles. LEFT/RIGHT after first frame still moves grid focus.
- Settle: 500ms after focus. Mute before `playChannel`. No chrome. Spinner until first frame, cap **4s**, then fail closed to logo only (no extra error copy; Mini Guide's `Preview unavailable` chrome stays Mini Guide-only).
- Focus move / viewport leave / filter-search signature change / ad index / audio-only / Search overlay / rail focus / modal / app `inactive`/`paused`: epoch++, stop, dispose.
- **Dwell:** flag on → `focusPlayDelay` is null. Flag off → keep today's 1200ms ten-foot dwell. 500ms and 1500ms of focus with flag on must not call `onChannelSelected`.
- **OK/select:** epoch++, **await** `stop()` then `dispose()` (catch errors), **then** `onChannelSelected`. Do not start Watch on the same tick as peek dispose.
- **Never start, and stop if running, when:** main session is playing (`iptvStreamingServiceProvider` playbackState playing), `isFullscreenModeProvider` is true, Mini Guide is open, MultiView is open, or Cast is active (`iptvCastProvider`). Do not use `showVideoStage` (ten-foot peek is the path where that flag is already false). Do not special-case `decoderBudget == 1`; Cast always skips peek.

### TV 19 amendment (copy into implementation issue)

Library may create one muted peek session. It is the Mini Guide session class, not a destination-owned Watch session. Teardown rules: leaving Library releases peek; opening Watch releases peek then starts main; Mini Guide still releases only its own preview. Destinations still must not hold the **main** session.

### Flags

- EPG now-playing text: on by default, no flag.
- TV peek: `browseGridTvPeekEnabled`. Default **off** on every TV build until Fire TV qualification. Debug desktop may override on. Phone ignores the flag (no peek).

### Tests

- Flag off: 1200ms ten-foot dwell still calls `onChannelSelected`.
- Flag on: 500ms and 1500ms focus do not call `onChannelSelected`; OK awaits fake preview `dispose` before `onChannelSelected`.
- One overlay view: `buildVideoView` count == 1 after scrolling past 50 tiles.
- EPG: null window → category; load failure → category; remap match after window lands → title; empty title omitted.
- Dense grid: no overflow (subtitle still dropped).
- Skip peek on ad, audio-only, Cast, main playing, Mini Guide, MultiView, fullscreen.
- 4s timeout fail-closed to logo.
- Lifecycle paused and Search overlay release the fake preview even when channel ids are unchanged.
- Mute + dispose order (no ghost audio). Do not log stream URLs.

### Out of scope

N live tiles, Instagram layout, new engine, web fake clips, changing MultiView cap, peek audio, phone hold-to-peek, compact-grid density work from the chrome branch.

## Success Criteria

- TV with `browseGridTvPeekEnabled` on: focus 500ms shows muted video or fail-closed logo; focus does not start Watch; OK starts Watch only after peek dispose completes; at most one overlay peek decoder; leave grid / pause / Search releases it; no ghost audio. Flag off: today's 1200ms dwell unchanged.
- Phone+TV: tiles that show a subtitle and have an EPG match show the current title without opening Watch.
- Cast, main playing, Mini Guide, MultiView, or fullscreen: peek does not start (or stops if running); existing playback untouched.
- Widget tests above green. Fire TV qualification still required before `browseGridTvPeekEnabled` default-on.
