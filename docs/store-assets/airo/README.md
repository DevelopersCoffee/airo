# Airo store assets — `io.airo.app`

Captured on the Pixel 9 rig (physical device, per WORKFLOW.md — not an emulator)
and processed with `scripts/process-store-screenshots.py`.

| Asset | Size | Notes |
| --- | --- | --- |
| `feature-graphic-1024x500.png` | 1024x500 | Generated by `scripts/make-feature-graphic.py --preset airo` |
| `airo-coins-home.png` | 1137x2274 | Money home with sample expenses |
| `airo-mind.png` | 1137x2274 | Assistant surface |
| `airo-beats.png` | 1137x2274 | Music surface |

All meet APKPure's constraints: 24-bit RGB with no alpha, minimum dimension
>= 320, maximum <= 3840, and a maximum no more than twice the minimum. The OS
status bar is cropped: it carries the device owner's notification icons, and
SystemUI demo mode does not hide them on this build.

## Deliberately not included

**Budgets screen.** The budget card reports a "spent" figure that does not match
the expenses on the device (~9,000 shown against 1,730 of actual expenses).
Until that is explained or fixed, it is not an honest thing to put on a store
page.

**Live TV / now-playing.** Those screens show third-party channel branding from
a user-supplied playlist. Airo bundles no channels, and a store screenshot
implying otherwise contradicts the claim the project makes everywhere else.

## Regenerating

```bash
# feature graphic
python3 scripts/make-feature-graphic.py --preset airo \
    --out docs/store-assets/airo/feature-graphic-1024x500.png

# screenshots: sign in on the device yourself, then capture per screen
python3 scripts/capture-store-screenshots.py --name home
python3 scripts/process-store-screenshots.py --input-dir <raw> --output-dir <out> ...
```
