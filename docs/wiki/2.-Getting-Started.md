## Android Installation

### Direct APK Installation

1. Download the latest APK to your Android device.
2. Verify the APK checksum with the release `SHA256SUMS` file.
3. Open the APK from your downloads or file manager.
4. Allow installation from the browser or file manager if Android asks.
5. Confirm installation and open Airo.

See the [download verification guide](../../VERIFY_DOWNLOAD.md) before
installing direct-download APKs.

### ADB Installation

Use this if you are installing from a development machine:

```bash
adb install -r app-release.apk
```

If the package targets a newer platform build, use:

```bash
adb install -t -r app-release.apk
```

## Web

Download the web build zip from releases, extract it, and serve the built files
from a local or hosted static web server. Modern Chrome is the recommended
target for the best PWA behavior.

## Development Setup

For contributors, use the repository setup commands:

```bash
make setup
make run-android
make run-ios
make run-web
```

See the main [README](../../README.md) and [getting started docs](../getting-started/START_HERE.md)
for development prerequisites.
