# Using Core Capabilities

## AI Chat

Use the Assistant tab for open-ended chat and supported app commands.

1. Open **Assistant**.
2. Type a message or tap a prompt card.
3. Airo first checks whether the message matches a supported app action.
4. If no local command matches, Airo asks the AI service for a response.

Examples:

- `Help me think through a task`
- `Make me a 7 day vegetarian diet plan`
- `Create a morning study routine for tomorrow`

## Airo Coins — In development

Airo Coins is not yet a publicly released capability. Its approved first
direction is a focused, local-first vault journey for organizing essential
financial records:

- Enter through a clear locked boundary.
- Scan grouped summaries without exposing full sensitive values.
- Reveal or copy a selected value through an intentional interaction.
- Return to a locked state on background, timeout, or manual lock.

These outcomes remain **in development** until a published release proves
availability. The concept does not provide banking, payments, money transfer,
investments, token value, returns, or financial advice.

Legacy Dashboard, balance, transaction, budget, expense, group, and split-bill
code may still appear in repository history or source routes. It is not the
public Airo Coins product contract. Follow the current status at
[Airo Coins](https://developerscoffee.github.io/airo/coins/).

## LifeTrack

Use LifeTrack to manage long-running personal workflows that have milestones,
action items, required inputs, and status updates.

Open LifeTrack from the `/life-track` route. The list screen supports:

- switching between board and list views
- filtering tracks by category
- opening a track card to view its details
- changing a track status from the card action menu

The detail screen opens at `/life-track/<trackId>`. It shows the selected
track's progress, grouped milestones, and action items. From the detail screen,
you can:

- change an action item status
- save text, number, link, and note-style inputs
- attach supported document files: PDF, JPG, JPEG, PNG, TXT, DOC, or DOCX
- pick and save required dates
- toggle boolean requirements such as completion confirmations

If a track cannot be found or local LifeTrack data cannot be opened, Airo shows
a local error state instead of generating an AI answer.

## Quest File Analysis

Use Tasks when you want to work with files.

1. Open **Tasks**.
2. Tap **Create Quest** or the add button.
3. Enter a title.
4. Upload one or more supported files: PDF, JPG, JPEG, PNG, TXT, DOC, or DOCX.
5. Continue into the quest chat.

## Ask Image

The Assistant routes image-analysis intent to the Quest upload flow.

1. Open **Assistant**.
2. Use the **Ask Image** card or ask about an image/receipt.
3. Airo opens **Tasks > New Quest** so the image can be uploaded and discussed.

## Audio Scribe

Audio Scribe is planned as an offline transcription workflow. The current
Assistant response maps this to Airo voice workflows and the future
meeting-minutes pipeline.

Saved meeting intelligence search is validated locally against representative
edge cases. The current in-memory contract supports title and project lookup,
speaker-label lookup, representative typo recovery, mixed-language tokens, and
stable deterministic ordering for repeated queries.

Saved meeting intelligence also generates structured local sections for summary,
decisions, risks, open questions, follow-ups, blockers, dependencies, and next
steps from final redacted transcript content.

### Meeting background intelligence — Under qualification

In supported full-app meeting flows, completing a meeting now accepts local
summary and search-index preparation as background work so the completion
action does not wait for those transforms. Only final, redacted transcript
segments enter these stages. Embeddings, speaker clustering, and Memory updates
remain unavailable until their real local providers are qualified.

This is currently an in-process background boundary. App termination, reboot
recovery, and operating-system rescheduling are still under qualification and
must not be treated as durable completion. TV and Coins profiles exclude the
meeting-intelligence module.

## Experimental Phone-to-TV Playback

Qualified development builds can expose **Stream > Play file on TV** by
launching with:

```bash
flutter run --dart-define=ENABLE_PHONE_MEDIA_RECEIVER=true
```

The phone serves the selected personal video over the local Wi-Fi network for
the active session. The receiver streams byte ranges and does not retain a
movie-file copy. This capability is experimental and remains hidden in normal
builds until receiver pairing, device qualification, recovery, and launch-gate
evidence are complete.
