# Troubleshooting and FAQ

## App Does Not Install on Android

- Confirm the APK downloaded completely.
- Allow installs from the browser or file manager used to open the APK.
- Try ADB installation with `adb install -r app-release.apk`.

## Login Redirects Me Back to Sign In

Airo can protect app routes behind authentication. Follow the guidance shipped
with the specific release profile you installed; repository routes are not by
themselves proof that a module is publicly available.

## On-Device AI Is Not Available

Not every device supports Gemini Nano. If unsupported, Airo can show cloud AI
mode. On-device availability depends on device model, OS support, and runtime
configuration.

## Assistant Command Did Not Work

Try one of the known prompt cards first. If a message is not recognized as a
supported local command, Airo treats it as a general AI chat prompt.

Schedule questions such as **Check my schedule for today** should list today's
events from every connected device calendar, or ask you to allow calendar
access. They should not ask whether you mean work or personal. If the Assistant
cannot read the calendar, open **Calendar** from the Assistant hub and tap
**Allow Calendar Access**, or enable Calendar for Airo in system settings.

## Quest Upload Failed

- Check that the file type is supported: PDF, JPG, JPEG, PNG, TXT, DOC, or DOCX.
- Try a smaller file.
- Reopen the Tasks tab and create a new quest.

## TV or Music Playback Fails

- Check network access for stream URLs.
- Try a different channel or track.
- Restart the app if the player state appears stuck.

For configured Xtream sources, open TV settings and review the source health
summary. Airo keeps a bounded, local history of categorical request outcomes
and can distinguish recent credential, network, server, rejected-request, and
unreadable-data failures. The summary never stores or displays source URLs,
credentials, response bodies, or raw exception text. **Health not measured**
means the source has not produced enough runtime evidence yet.

## My Playlist Source Will Not Load

If none of your configured playlist sources can be reached, the channel screen
says so and offers **Retry** rather than sending you back to the "Add your
playlist" setup view. Retry re-contacts the sources; it does not just redraw the
last result.

- One source failing does not hide the channels from your other sources. Airo
  loads whatever it can and falls back to each source's own cached copy.
- The message reports how many sources failed and never shows a source URL,
  since playlist URLs can contain private tokens.
- A source that answers but carries no channels is not a failure. Check the URL
  in the playlist sources sheet if a source stays empty.

## Cast Button Is Missing on macOS

Airo currently shows Google Cast controls only on Android and iOS, where the
Google Cast sender bridge is available. The macOS app does not reuse the mobile
Cast sheet because that path cannot discover or connect to Chromecast devices
from desktop builds.

On macOS, use local playback for now. Desktop casting support needs a dedicated
native sender, AirPlay route, or system-player design before the Cast action can
be enabled there.

## Play File on TV Is Missing

The Aika Stream build exposes phone-local playback on supported Android and iOS
touch layouts. In the full Airo mobile app, qualified development builds must
opt in with `--dart-define=ENABLE_PHONE_MEDIA_RECEIVER=true`. Both devices must
be on the same local Wi-Fi network. The feature is not available on ten-foot TV
layouts, desktop, cloud relay, AirPlay, or general transcoding paths.

## Fire OS and Vega OS

Aika Stream has two Android TV distribution lines. Google Play builds use
`APP_VARIANT=tv`. Fire OS builds use `APP_VARIANT=fireTv` with the same
`lib/main_tv.dart` entrypoint. On a Fire OS binary, the Aika Stream card in
TV Settings points at the Amazon Appstore package link instead of Google
Play. That Amazon listing is not published yet.

Vega OS devices, including the Fire TV Stick 4K Select, cannot install
Android APKs. There is no Vega build. The supported install for your own
playlist is Google Play on Android TV or Google TV, package
`com.developerscoffee.tv.midas`.

Do not install a player from a Downloader code or an APK sent in a direct
message. Match the store listing and the package name. Do not grant a media
app Accessibility or SMS permission.

If playback buffers, clear the app cache only. Clearing app data removes
the playlist saved on the device. Then free storage, try the hardware
decoder, restart the device, and test the same playlist on another device.

## FAQ

**Q: Is Airo only an AI app?**
A: No. Airo is a modular platform for focused experiences. Aika Stream is
available, Airo Coins is in development, and other module areas retain their
own evidence-backed claim states.

**Q: Does Airo work offline?**
A: Some workflows are designed for local or offline execution, especially
on-device AI where supported. Media streaming, downloads, cloud fallback, and
release installation require network access.

**Q: What games are available?**
A: Chess and Blackjack are documented as available. Additional games are planned
or documented as coming soon.

**Q: Why do loading and error messages change wording each time?**
A: Airo rotates through a small catalog of status messages (for example
"Thinking…", "One sec…", "Hmm, that didn't work.") instead of repeating
"Loading..." everywhere. When an operation fails, the technical detail is
still shown under the friendly headline, so nothing useful is hidden.

**Q: Where should I report issues?**
A: Use GitHub Issues from the Feedback page.
