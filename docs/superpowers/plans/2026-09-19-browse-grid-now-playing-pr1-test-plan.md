## Affected Pages/Routes

- Aika Stream Library / Live channel grid (`ChannelLibraryGrid`) — now-playing subtitle and TalkBack label.

## Key Interactions to Verify

- Open Library with XMLTV matched: tile subtitle is current program title, not category.
- Open Library with no XMLTV: subtitle stays category · flag · language (regression).
- D-pad focus: TalkBack/semantics include program title when present.
- Dense 5-column phone grid: no overflow; subtitle may be absent.

## Edge Cases

- `forwardLoadFailed` but window already has now: titles still show.
- Empty / whitespace program title: category remains.
- Duplicate tvg-id: first playlist channel gets the title; sibling stays category.
- Ticker: when a program ends inside the loaded window, subtitle updates without restarting the app.

## Critical Paths

- Cold start: first Library open may show category then titles once the 6h window lands. Must not crash. Must not start a video decoder.
